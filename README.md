# Générateurs de grilles de calcul mental — CE1

Deux générateurs de fiches de calcul mental pour le CE1, utilisés avec les
ceintures de calcul mental de la classe : une fiche nouvelle à chaque clic,
avec son corrigé, à imprimer ou à faire sur écran.

## ✨ Ce que les outils proposent

### Générateur de grilles (`generateur_grilles.html`)

- **Table stricte, terme manquant, soustraction associée** : 3 blocs
  (sans passage de dizaine, avec passage, mélange), 20 + 20 + 32 calculs.
- **Défis vitesse** (3 manches de 18) et **blocs uniques** (40 calculs, type micetf) :
  additions seules, soustractions seules ou mélangées.
- **Doubles, presque-doubles** (jusqu'à N) et **tables de multiplication**.
- **Chrono par bloc** : la durée est calculée sur le nombre de calculs
  (4,5 s par calcul, 6 s en soustraction), avec démarrage, pause et arrêt.
- **Vérification sur écran** : précision (acquis / en cours / non acquis)
  et fluence si le temps est respecté.

### Générateur de soutien adapté (`generateur_soutien.html`)

- **Même logique, version adaptée** : 26 calculs (8 + 8 + 10), écriture plus
  grande, petits nombres d'abord, nombres jusqu'à 29, 49 ou 99, **sans chrono**.
- **Coup de pouce** imprimé sur la fiche, adapté au type et à la table :
  passer par la dizaine, regarder les unités, penser à l'addition,
  chercher le double caché…
- **Tableau des nombres** (dizaines grisées) en appui visuel.
- Coup de pouce et tableau se décochent pour retirer l'aide progressivement.
- Types : table stricte, terme manquant, soustraction associée, doubles,
  presque-doubles, moitiés.

## 👩‍🏫 Pour l'enseignant·e

1. Choisir le type de fiche et la table (N), puis « Générer une nouvelle grille ».
2. Cocher « Corrigé » pour afficher les réponses.
3. Imprimer, ou télécharger en HTML ou en PDF.

Le **nom de chaque type de fiche** (`table_stricte`, `terme_manquant`,
`soustraction_associee`, `soutien_terme_manquant`…) est le même que dans
l'outil de saisie des résultats du suivi de classe : les résultats saisis
retrouvent le bon format, le bon nombre de calculs et le bon temps.

## 📐 Choix pédagogiques

- Progression **sans passage → avec passage → mélange** dans chaque fiche :
  l'élève consolide la procédure avant de la mêler aux autres calculs.
- Nombres **dispersés sur les dizaines** et formes commutées (a + N et N + a,
  trou à gauche et à droite) pour éviter les automatismes de position.
- Le soutien garde la même structure que la fiche de la classe : l'élève aidé
  travaille la même notion, avec moins de calculs, plus d'appuis et sans
  pression du temps.

## 🚀 Utiliser sans installation

Aucun compte, aucune installation, aucune donnée personnelle collectée (seul un
comptage anonyme des visites, sans cookie, via GoatCounter) : tout fonctionne
dans le navigateur.

- Site en ligne : <https://eautsu.github.io/ceintures_calcul_mental/>
- Pour utiliser dans une école : ouvrir simplement le lien, ou télécharger
  les fichiers du dépôt et ouvrir `index.html`.
